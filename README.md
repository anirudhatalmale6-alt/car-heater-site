# 12V Car Heater & Defroster - one-page site

Single `index.html`, no build step. To change the store name, price, shipping line
or where "Order now" goes, edit the `SHOP` block near the bottom of `index.html`.

Photos in `assets/` are the supplier's listing photos (cropped out of phone
screenshots, 800x800). Every photo box on the page is square, so a replacement
should be square too.
